# Everlasting Wedding Invitation

Aplikasi web statis sederhana untuk membuat undangan pernikahan digital yang interaktif. Proyek ini dirancang untuk memudahkan pasangan pengantin dalam merancang tampilan informasi pernikahan, melampirkan foto mempelai, serta menyertakan tanda tangan digital secara langsung di dalam peramban (*browser*).

## Latar Belakang Masalah
Pembuatan undangan digital sering kali membutuhkan proses desain grafis yang rumit atau platform berbayar. Aplikasi ini hadir sebagai solusi praktis, cepat, dan mandiri bagi pengguna untuk menghasilkan draf kartu undangan pernikahan digital yang bersih, elegan, dan siap cetak/simpan dalam format PDF.

## Target Pengguna
* Calon pengantin yang ingin membuat pratinjau kartu undangan sederhana secara cepat.
* Pengguna umum yang membutuhkan alat bantu pembuatan undangan digital berbasis web yang ringan.

## Teknologi yang Digunakan
* **HTML5:** Struktur dasar tata letak halaman web dan form input.
* **CSS3:** Desain antarmuka (*UI/UX*), tata letak responsif (*Flexbox & Grid*), dan pengaturan gaya cetak (*Print Media Query*).
* **JavaScript (ES6+):** Logika interaksi form, pembacaan file gambar (*FileReader API*), serta manipulasi elemen *Canvas* untuk tanda tangan digital.
* **Platform Publikasi:** GitHub Pages.
